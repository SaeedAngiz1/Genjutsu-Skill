## Release blurb

Genjutsu Skill gives Claude Code and Codex a complete character replacement workflow from one detailed request: inspect the source, choose depth/face-mesh/combined preparation, review the guidance, generate an authorized draft, recover existing jobs and export with the original soundtrack.

Includes an installable skill, bundled Python runtime, installation helpers, focused recovery checks and a validation report. Bring your own clips, references, Replicate and Enhancor accounts. Cloud inference is paid; Windows runtime setup uses WSL2. Read `docs/VALIDATION.md` for what has actually been tested.
